# Show HN - Airship – Figma-Like Visual Editor for Claude Code, Codex and OpenCode

> Source: [Hacker News Show HN](https://github.com/0xnyn/airship)

<p>I wanted to experiment with my UI like I do in Figma, without having to rebuild it in a separate design tool. So I built Airship.<p>It lets you prototype directly in your running app, select elements, make changes, and explore different directions visually.<p>Once you like something, Airship applies the changes to your source. No mockups to keep in sync, or bouncing back and forth between design and code.</p>
