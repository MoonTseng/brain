# Show HN - Sketchling – a hand-drawn animation language for coding agents

> Source: [Hacker News Show HN](https://github.com/AnayGarodia/sketchling)

<p>I built sketchling this weekend to see if agents can draw something that looks natural and hand-drawn if given the right primitives. This was inspired by Manim after watching how powerful an agent-native way to produce animations can be.<p>It is a small typescript library with shapes that take character parameters like weight, looseness, and energy. It renders through rough.js and GSAP through a headless chromium browser. It has tools like a built-in linter and is meant to be agent-native.<p>
